This folder contains preview images for the portfolio project.

## Sample Images:

These placeholder images will be replaced with actual screenshots of your portfolio:

- **hero-section.png** - Screenshot of the hero section with introduction and CTA buttons
- **projects-showcase.png** - Screenshot showing the projects section with project cards
- **tech-stack-preview.png** - Screenshot of the technology stack display
- **full-page-preview.png** - Full page screenshot of the portfolio

## How to Add Your Images:

1. Take screenshots of each section of your portfolio
2. Optimize them for web (recommended: 1200x800px for full-page, 600x400px for sections)
3. Convert to PNG or WebP format for best quality
4. Replace the placeholder file names with your actual image files
5. Update README.md if needed with the correct image paths

## Image Naming Convention:

- Keep filenames lowercase
- Use hyphens instead of spaces
- Be descriptive about what each image shows
- Example: `hero-section-dark-theme.png`
